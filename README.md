# Классификатор обращений

Небольшой Python-скрипт для классификации обращений пользователей.

Программа читает 5 обращений из файла `messages.txt`, определяет категорию каждого обращения и выводит черновик ответа на русском языке.

Используются три категории:

- **справка** — информационные вопросы;
- **жалоба** — сообщения о проблемах;
- **другое** — остальные обращения.

Для классификации используются простые правила и ключевые слова. Подключение LLM и интернет не требуются.

## Как запустить

Нужен Python 3.

В терминале в папке проекта выполните:

```bash
python main.py
```

После запуска программа выводит исходный текст обращения, его категорию и черновик ответа.

## Результат

Скрипт обрабатывает все 5 обращений из задания и автоматически формирует категорию и ответ для каждого обращения.
